# 图像缓存预览（Image Cache Preview）

[English](image_cache.en.md) | [返回首页](../README.zh-CN.md)

在原生图像预览的基础上增加历史回看：每张流经本节点的图自动留档，节点内大图下方有一行缩略图，点小图即切大图；缩略图条能显示的张数随节点宽度实时增减，配翻页与上一张/下一张按钮。`image` 输出原样透传，可插在采样器与保存节点之间的任意位置。

**分类：** `0DAYE`

## 输入 / 输出

| 输入 | 说明 |
|---|---|
| `image` | 待预览的图片（必接）。流经本节点时自动写入历史缓存 |
| `history_key` | 高级选项，默认 `-1`。`-1` = 自动：前端在节点创建时写入当前节点实例编号，每个节点各自独立一份历史；填相同数字则多个节点共享同一份历史 |

| 输出 | 说明 |
|---|---|
| `image` | 原样透传输入图（**原始分辨率**，不受缓存缩图影响），可继续接保存节点或其它下游 |

节点标记为输出节点：**即使输出端口没连线，只要图流经它就会执行并记录**。

## 面板布局

```
┌───────────────────────┐
│                       │
│        大图预览        │  ← 随节点拖拽缩放（最小约 160px）
│                  3/50 │  ← 右下角角标：第几张 / 共几张
├───────────────────────┤
│ □ □ □ □ □ □ □ □       │  ← 缩略图条：左新右旧，当前张高亮描边
├───────────────────────┤
│ ⏮ ‹ 1/5 › ⏭ │ ◀上一张 下一张▶ 清空 │
└───────────────────────┘
```

- **缩略图条自适应**：每页张数 = 缩略图条宽度 ÷ 单张宽度（56px + 间距），拖动节点边框或缩放节点时实时重算，页数跟着变。
- **新图优先**：每次执行完成后强制回到最新（第 1 页、第 1 张）；batch 一次出多张时全部入历史，默认显示 batch 第一张。
- **点小图切大图**：缩略图上单击即把该图显示到大图区，角标同步更新。

## 操作栏

| 按钮 | 行为 |
|---|---|
| `⏮` | 跳到最新一页（第 1 页），大图切到该页最新一张 |
| `‹` | 上一页（更新的图） |
| `›` | 下一页（更旧的图） |
| `⏭` | 跳到最旧一页（最后一页） |
| `◀ 上一张` | 大图切到更新的一张；跨页时自动翻页 |
| `下一张 ▶` | 大图切到更旧的一张；跨页时自动翻页 |
| `清空` | 清空本节点的历史列表（二次确认） |

**「上一张 / 下一张」的方向**：缩略图条按时间轴排列（**左新右旧**，最新一张在最左），所以「上一张」= 更新的图（向左），「下一张」= 更旧的图（向右）。到两端时按钮自动置灰。

## 右键菜单

在**大图区**或**任意缩略图**上右键，弹出与原生预览节点一致的操作（作用于被右键的那张图）：

| 菜单项 | 有原图时（任意模式） | 原图已失效时 |
|---|---|---|
| 打开图像 | 新标签页打开**原图**（全分辨率 PNG） | 打开 1024px 预览图 |
| 复制图像 | **原图**复制到剪贴板 | 预览图复制到剪贴板 |
| 保存 PNG 原图 | 下载**原图 PNG（内嵌 prompt/workflow 元数据，可拖回 ComfyUI 恢复工作流）** | —（降级为「保存图像」，存预览图） |
| 保存 JPG | 原图**即时转码 JPG**（质量 95，EXIF 内嵌 CivitAI 参数串） | —（同上降级） |
| 打开图片路径 | 资源管理器定位并选中缓存文件（优先原图，失效则定位预览图） | 同左 |

**保存的图都能被 CivitAI 读出**：PNG 原图走 tEXt `parameters` 块，JPG 走 EXIF UserComment，内容都是 A1111 格式生成参数串（正面/负面提示词、Steps/Sampler/CFG/Seed/尺寸/模型/LoRA 哈希）——这正是 CivitAI 的读取点。PNG 原图在此基础上还多带 prompt/workflow（可拖回 ComfyUI 恢复工作流）。

## 完整 / 轻量模式

节点上有个高级选项 **store_full_image**（默认开）：

- **开（完整模式）**：每组多存一份全分辨率 PNG 到 `user/0DAYE/` 永久保留，右键保存得到原图带数据；单组约 1~4MB
- **关（轻量模式）**：`user/0DAYE/` 里只存 1024px 预览图（仍带 CivitAI 参数串），单组约几十 KB；**全分辨率原图改存 ComfyUI 官方 `temp/` 目录**——本次会话内右键照样能存 PNG 原图或 JPG（原图即时转码），**重启 ComfyUI 后由官方机制自动清空**（启动和关闭都会清），之后这些历史项只能存预览图。适合想要原图随存随取、又不想让原图长期占盘的场景

## 容量与磁盘占用

采用**两级容量**，磁盘占用与节点数量、工作流数量无关：

| 层级 | 上限 | 说明 |
|---|---|---|
| 每节点历史（抽屉） | 50 条 | 每个 `history_key` 一份轻量索引（只有 id 与尺寸），多个节点互不影响 |
| 全局图片池 | **300 组** | 所有节点共享；超出按 LRU 淘汰最旧的，并自动从各节点列表里摘除 |

所以无论您建多少个预览节点、保存多少个工作流，缓存目录里的图最多就是 300 组。

- 完整模式每组三个文件：大图长边 **1024px**（节点内显示）、缩略图长边 **160px**、**全分辨率 PNG（内嵌工作流元数据）**；轻量模式在 `user/0DAYE/` 只有前两个文件，全分辨率 PNG 落在官方 `temp/`（会话级，重启即清，不占这里的配额）。
- 大图/小图无透明通道的存 JPEG（质量 92），带 alpha 的存 PNG。
- 磁盘占用粗估：完整模式 300 组约 **0.3~1.2GB**（取决于出图分辨率）；轻量模式 `user/0DAYE/` 侧 300 组约 **20~60MB**，`temp/` 侧随本次会话出图量累积、关闭 ComfyUI 即释放。

## 存储位置

全部数据在 `ComfyUI/user/0DAYE/` 下，**插件更新、重装、ComfyUI 重启都不会丢**：

```
ComfyUI/user/0DAYE/
├── image_cache/                     # 缓存图片（{id}_p 大图 / {id}_t 小图 / {id}_f 全分辨率PNG）
└── image_cache_history.json         # 各组尺寸索引 + 各节点抽屉清单
```

与官方目录的关系：

| 目录 | 写入者 | 特点 |
|---|---|---|
| `temp/` | 原生预览类节点；**本节点轻量模式的原图**（`temp/0DAYE_image_cache/`） | 启动/关闭 ComfyUI 都会自动清空 |
| `output/` | 保存类节点 | 永久保留，会出现在「资产」面板 |
| `user/0DAYE/image_cache/` | **本节点**（预览图/缩略图 + 完整模式原图） | 重启保留、不占资产面板、由全局 300 组硬顶自动淘汰 |

**「清空」按钮只清本节点的列表，不删缓存文件**——文件是全局池共用的资源，可能还被其它节点引用，只在超过 300 组时按 LRU 自然释放。

## 双引擎兼容

预览面板为纯 DOM 实现，LiteGraph（旧画布）与 Nodes 2.0（Vue 画布）通用，两引擎之间切换无需刷新页面。大图区随节点缩放（最小约 160px），缩略图条与操作栏固定高度。
