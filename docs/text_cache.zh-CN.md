# 文本缓存（Text Cache）

[English](text_cache.en.md) | [返回首页](../README.zh-CN.md)

接住上游 LLM 节点（提示词扩写/翻译等）输出的文本：跑一次得到好结果后，不必每次跑图都重新调 LLM。

**分类：** `0DAYE`

## 模式（`mode`）

| 模式 | 行为 |
|---|---|
| `自动`（默认） | 按优先级：① `override_text` 非空 → 输出并记入历史；② 上游 `text` 非空 → 直通并记入历史；③ 否则（上游被静音/未接）→ 输出 `历史[history_index]` |
| `上游` | 无条件输出上游 `text`（非空时记录） |
| `历史` | 无条件输出 `历史[history_index]`——复用上一轮结果 |

## 输入 / 输出

| 输入 | 说明 |
|---|---|
| `text` | 接上游 LLM 输出——纯连线端口（绿色圆点、无文本框，optional 故位于其它控件下方）。上游组被**静音（Ctrl+M）**时收不到数据 → `自动` 模式自动回退历史 |
| `trigger_text` | 动态触发词——纯连线端口，接 LoraManager 等加载器的 `trigger_words` 输出；只有 active 开启的 LoRA 贡献词。未接/静音时忽略 |
| `prefix_switch` | 手动前缀开关（默认关）。关闭时 `prefix` 文本框折叠隐藏、其中的词不参与拼接；`trigger_text` 动态端口不受影响 |
| `prefix` | 手动触发词前缀（多行文本框，逗号/中文逗号/换行分隔多个；框前小圆点可拖线转端口，接线后控件收起、端口可见可断开），恒拼在最终输出**段首**，与模式无关；可随时增删改，仅在 `prefix_switch` 开启时参与拼接 |
| `override_text` | 手动覆盖文本（多行文本框，也可从框前小圆点拖线转端口）。`自动` 模式下优先级最高，输出并记录。清空即恢复上游（面板标题栏有 `清空下框` 按钮一键清空） |
| `history_key` | `-1` = 自动（每个节点实例按实例编号各自独立一份历史）。多个节点填相同数字则共享一份历史 |
| `history_index` | 输出第几条历史：`0` = 最近一条，最大 `49` |

输出：`text`（结果文本）、`history_list`（编号历史清单含全文，`⏎` 为换行占位符）。

## 触发词前缀（LoRA keywords）

最终输出恒为：

```
prefix 框各词 + trigger_text 端口各词（保序、去重）+ ", " + 模式决定的主体文本
```

- 触发词固定在**段首**（CLIP 位置注意力，前段 token 权重更高）；手动框的词排在动态端口之前。
- 手动框与动态端口是**叠加**关系：LoraManager 没附带触发词的 LoRA（自训/无 CivitAI 元数据）直接在 `prefix` 框里补词。
- 记入历史的始终是拼接后的完整文本；从历史 `回填` 的全文若已带当前前缀，不会重复拼接。
- **冻结主体后仍可改词**：`override_text` 固定的是主体，`prefix` 独立在外——冻结后增删触发词，下次出图立即生效，不破坏冻结。
- 典型接线：`Lora Loader (LoraManager).trigger_words` → `trigger_text`；LLM 输出 → `text`；节点输出 → CLIPTextEncode。配合 Save Image Metadata 节点时，含触发词的完整文本经历史回退在同一遍运行内写入图片元数据，无需跑两遍。

## 历史

- 每个 key 保留最近 **50** 条，去重（与最新一条相同不重复入列）
- **持久化保存**：写入 `ComfyUI/user/0DAYE/text_cache_history.json`（用户数据目录，插件更新/重装不丢），重启 ComfyUI 后自动恢复，不影响工作流里的历史记录
- 节点内面板列出历史条目：悬停查看全文，每行带 `复制`（复制到剪贴板）和 `回填`（填回 `override_text`）按钮；标题栏有三个清空按钮——`清空上框`（清 `prefix`）、`清空下框`（清 `override_text`）、`清空历史`（清本节点历史，含磁盘文件，不可恢复）；每次运行后自动刷新，重启后面板直接恢复显示

## 使用提示

- 固定上一次好结果：**静音（Ctrl+M）上游 LLM 组**——`自动` 模式会持续输出上一轮文本。**绕过（Ctrl+B）不会触发**该行为：绕过是数据原样透传，与实时输出无法区分，请改用显式 `历史` 模式或填写 `override_text`。
- `回填` 会把选中条目写入 `override_text` 并把 `mode` 切回 `自动`，填入文本立即生效。
- 界面：`text` 为纯连线端口（无文本框）；历史面板底部有独立拖拽手柄，**只单独调整面板高度（80–1000px）**，不影响上方提示词输入框与其它控件；拖动节点右下角则只拉高 `override_text` 文本区（前端原生行为）。面板高度随工作流保存，重载后保持。
