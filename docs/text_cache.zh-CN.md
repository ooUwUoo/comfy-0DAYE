# 文本缓存（Text Cache）

[English](text_cache.en.md) | [返回首页](../README.zh-CN.md)

接住上游 LLM 节点（提示词扩写/翻译等）输出的文本：跑一次得到好结果后，不必每次跑图都重新调 LLM。

**分类：** `0DAYE`

## 模式（`mode`）

| 模式 | 行为 |
|---|---|
| `自动`（默认） | 按优先级：① `override_text` 非空 → 输出并记入历史；② 上游 `text` 非空 → 直通并记入历史；③ 否则（上游被静音/未接）→ 输出 `历史[history_index]` |
| `上游` | 无条件输出上游 `text`（非空时记录） |
| `历史` | 无条件输出 `历史[history_index]`——复用上一轮结果 |

## 输入 / 输出

| 输入 | 说明 |
|---|---|
| `text` | 接上游 LLM 输出——纯连线端口（绿色圆点、无文本框，optional 故位于其它控件下方）。上游组被**静音（Ctrl+M）**时收不到数据 → `自动` 模式自动回退历史 |
| `override_text` | 手动覆盖文本（纯文本框、不可连线）。`自动` 模式下优先级最高，输出并记录。清空即恢复上游 |
| `history_key` | `-1` = 自动（每个节点实例按实例编号各自独立一份历史）。多个节点填相同数字则共享一份历史 |
| `history_index` | 输出第几条历史：`0` = 最近一条，最大 `49` |

输出：`text`（结果文本）、`history_list`（编号历史清单含全文，`⏎` 为换行占位符）。

## 历史

- 每个 key 保留最近 **50** 条，去重（与最新一条相同不重复入列）
- 仅存内存——**重启 ComfyUI 即清空**
- 节点内面板列出历史条目：悬停查看全文，每行带 `复制`（复制到剪贴板）和 `回填`（填回 `override_text`）按钮；每次运行后自动刷新

## 使用提示

- 固定上一次好结果：**静音（Ctrl+M）上游 LLM 组**——`自动` 模式会持续输出上一轮文本。**绕过（Ctrl+B）不会触发**该行为：绕过是数据原样透传，与实时输出无法区分，请改用显式 `历史` 模式或填写 `override_text`。
- `回填` 会把选中条目写入 `override_text` 并把 `mode` 切回 `自动`，填入文本立即生效。
- 界面：`text` 为纯连线端口（无文本框）；历史面板底部有独立拖拽手柄，**只单独调整面板高度（80–1000px）**，不影响上方提示词输入框与其它控件；拖动节点右下角则只拉高 `override_text` 文本区（前端原生行为）。面板高度随工作流保存，重载后保持。
