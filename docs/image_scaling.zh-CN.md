# 图像缩放（Image Scaling）

[English](image_scaling.en.md) | [返回首页](../README.zh-CN.md)

多功能图像缩放裁切节点：单一「选择比例」下拉 + 边长/像素/手动宽高三种缩放模式 + 边长倍数对齐 + 11 种裁剪方式 + 5 种重采样算法；允许空挂（不接图像）输出纯色底板，也可只取宽高数值当分辨率选择器。

**分类：** `0DAYE`

## 输入

| 输入 | 说明 |
|---|---|
| `图像` | 可选。待处理图像；不接图时输出目标尺寸的纯色底板（未设尺寸则为 1024×1024 白色） |
| `遮罩` | 可选。与图像同步做同样的缩放/裁切；「扩展并填充」新增的空白区域在遮罩中记为 0（透明） |

## 参数

### 选择比例

单一下拉（默认「关」）：1:1 / 2:3 / 3:2 / 3:4 / 4:3 / 9:16 / 16:9 / 21:9 / 9:21。

- **只选比例、不开任何缩放模式**：按接入图的像素面积适配新比例（总量不变），多余部分中心裁切。
- **比例 + 任一缩放模式同时开启**：二者叠加生效——比例决定「输出框形状」，缩放模式决定「尺寸大小」。

### 基础控制

| 参数 | 说明 |
|---|---|
| `边长倍数` | 输出宽高对齐到该倍数的整数倍（默认 16，适配绝大多数 VAE 潜空间）；「关」= 不限制 |
| `裁剪方式` | 原图如何贴合目标尺寸（11 种，见下节） |
| `缩放算法` | `area`（默认，最快，缩小首选）/ `lanczos`（质量最高）/ `bicubic` / `bilinear` / `nearest-exact`（不插值，像素画、遮罩用） |

### 三种缩放模式（优先级：像素 > 手动宽高 > 边长）

| 模式 | 参数 | 说明 |
|---|---|---|
| 📏 边长缩放 | `缩放至边`（最长边/最短边）+ `缩放长度`（32~4096） | 指定边缩到目标像素，另一边等比跟随；同时选了比例则按比例解算宽高 |
| 🖼️ 像素缩放 | `像素数量（百万）`（0.01~4.0）+ `分辨率步数`（1~3） | 按总像素目标自动算尺寸；步数 >1 且目标 <2MP 时渐进式缩放（大幅缩小画质更干净） |
| ✏️ 手动宽高 | `宽度` / `高度`（32~4096）+ `🔄 切换宽高` | 直接指定目标尺寸，比例不参与；切换宽高一键横转竖 |

三种模式全关且比例为「关」时：**纯透传**——图像仅按「边长倍数」对齐后输出，不重采样。

## 边长倍数对齐语义（只裁切/只缩小，绝不放大）

1. 两边都已是倍数 → 零改动；
2. 仅一边不合规 → 只把该边向下裁到最近倍数，另一边不动（如 1536×2732 → 1536×2720）；
3. 两边都不合规 → 以短边为基准等比缩小到倍数，长边同比例缩后再对齐（如 500×300 → 480×288），宽高比不走形。

## 裁剪方式

| 方式 | 行为 |
|---|---|
| 中心裁剪 / 对齐上边 / 对齐下边 / 对齐左边 / 对齐右边 | 等比放大到铺满目标框后裁掉多余部分（按所选位置对齐） |
| 拉伸缩放 | 直接拉伸变形到目标尺寸（不保宽高比） |
| 扩展并填充 白/黑/绿/蓝/灰 | 保留完整画面、等比缩到能完整放入目标框后居中，空白处填对应纯色（适合图像外扩、抠像占位）；遮罩新增区域记 0 |

比例单独生效且未选「扩展并填充」时，强制中心裁切。

## 分辨率上限保护

目标尺寸超过 **400 万像素**时自动等比缩小（仅在你主动设定了尺寸/比例时触发；纯透传不动原图）。

## 输出

| 输出 | 说明 |
|---|---|
| `图像` | 处理后的图像（批量同步处理） |
| `遮罩` | 处理后的遮罩（无遮罩输入时输出全 0） |
| `宽度` / `高度` | 最终输出尺寸数值——不接图像输出时，本节点可当**分辨率选择器**给文生图提供宽高 |

## 空挂行为（不接图像）

- 未设任何尺寸 → 输出 1024×1024 白色图片；
- 设了尺寸 → 输出该尺寸的纯色底板（默认白色；裁剪方式选「扩展并填充XX色」时输出对应颜色）。

## 双引擎兼容

节点基于官方 V3 DSL（`io.ComfyNode`）定义、无前端脚本，LiteGraph（旧画布）与 Nodes 2.0（Vue 画布）均可直接使用，工作流 JSON 双引擎互通。
