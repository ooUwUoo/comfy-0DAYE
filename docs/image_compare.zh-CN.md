# 图像对比（Image Compare）

[English](image_compare.en.md) | [返回首页](../README.zh-CN.md)

节点内的 A/B 图像对比预览：跑图直接在画布上划线/按住点击/混合对比，右键保存即得带工作流元数据的原始分辨率 PNG——不接保存节点也能出图存档。

**分类：** `0DAYE`

## 输入

| 输入 | 说明 |
|---|---|
| `image_a` | 可选。对比基准（左/底层）；只接这一个就是普通预览器 |
| `image_b` | 可选。对比对象（右/顶层）；**只接 B 也能预览**（双输出=B），之后想对比再接 A |

两个输入**接任意一个（或两个）都能预览**，一个都没接执行报错提示。

## 对比模式（预览区顶部按钮行）

| 模式 | 操作 |
|---|---|
| **划线**（默认） | 鼠标扫过图像区：分界线自动跟随指针，左侧显示 A、右侧显示 B；移开后整幅显示 A |
| **点击** | 在图像区**按住鼠标**显示 B，**松开**恢复 A（快速对照） |
| **混合** | 拖动透明度滑块，B 图以 0–100% 不透明度叠加在 A 图上（100%=纯 B，0%=纯 A） |

- **交换 A/B**：按钮一键交换两图身份（对比方向反转），信息行同步标注「已交换」。
- 模式 / 混合度是会话级状态，不写入工作流 JSON；执行刷新图片后保留。

## 右键菜单

在节点上（包括预览图上）右键：

| 菜单项 | 行为 |
|---|---|
| 复制 A 到剪贴板 | 把 A 图（预览分辨率）写入系统剪贴板（PNG，可直接粘贴到微信/PS 等） |
| 保存 A 图片 | 浏览器下载 A 图：**原始分辨率 PNG + 官方 SaveImage 同款 `prompt`/`workflow` 元数据，可直接拖回 ComfyUI 恢复工作流**（不想接保存节点时用它出图存档） |
| 复制 B 到剪贴板 | 同上，对 B 图 |
| 保存 B 图片 | 同上，对 B 图（原始分辨率 + 元数据） |

未执行的图不出现对应菜单项；交换后菜单里的 A/B 跟随当前显示身份。

## 输入 / 输出

| 输入 | 说明 |
|---|---|
| `image_a` | A 图（对比基准：左/底层；`image_a` 输出端口原样输出它）。**可选**：只接一个端口也能预览 |
| `image_b` | B 图（对比对象：右/顶层）。**可选**：只接 B 也能预览（双输出=B），之后想对比再接 A |

| 输出 | 说明 |
|---|---|
| `image_a` | A 图原样输出（原始分辨率张量；只接 B 时 = B） |
| `concat` | A\|B 左右拼接图：以 A 高度为准等比对齐（通道统一为 RGB）；B 未接或只接 B 时 = 该单图 |

## 预览防卡顿机制

送前端的预览图自动做 **GPU bicubic 下采样（长边 > 2048 才缩）+ PNG 无损编码**，经官方 temp 预览通道传输，重启自动清理——大图的 websocket 传输与浏览器解码开销小一个量级。**该下采样只影响面板显示与「复制到剪贴板」**；右键「保存图片」另写一份**原始分辨率** PNG（含工作流元数据）；两个输出端口永远是原始分辨率的完整图像数据。

## 信息行

预览区底部显示 A/B 的**原始分辨率**（如 `A: 1024×1536   B: 1024×1536`），与预览缩放无关。

## 双引擎兼容

预览区为纯 DOM 实现，LiteGraph（旧画布）与 Nodes 2.0（Vue 画布）通用。图像显示区**随节点缩放**：拖节点右下角整体放大/缩小时图像区跟着伸缩（最小约 120px），宽度随节点宽度。
